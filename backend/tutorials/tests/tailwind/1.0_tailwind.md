## Topic 1: What Is Tailwind CSS?

### The Core Idea

Tailwind CSS is a **utility-first CSS framework**. Instead of writing CSS like this:

```css
.card {
  background: white;
  padding: 1rem;
  border-radius: 0.5rem;
  box-shadow: 0 4px 6px rgba(0,0,0,0.1);
}
```

```html
<div class="card">Hello</div>
```

You write HTML like this:

```html
<div class="bg-white p-4 rounded-lg shadow-md">
  Hello
</div>
```

Every class does **one thing**:

| Class | What It Does |
|-------|-------------|
| `bg-white` | Sets background color to white |
| `p-4` | Adds padding on all sides (1rem) |
| `rounded-lg` | Rounds the corners |
| `shadow-md` | Adds a medium shadow |

### Why This Approach?

- **No naming things.** You don't waste time debating `.card` vs `.panel` vs `.box`
- **No jumping between files.** The style lives right next to the HTML
- **No unused CSS.** Tailwind only generates the classes you actually use
- **Consistency.** The spacing scale, colors, and sizes are predefined—no random `margin: 17px`

### The Mental Shift

Old way: "I need a button component. Let me write CSS for it."

Tailwind way: "I need a button. Let me combine `bg-blue-500`, `text-white`, `px-4`, `py-2`, `rounded` right in the HTML."

### Quick Example

Here's a simple button in Tailwind:

```html
<button class="bg-blue-500 hover:bg-blue-700 text-white font-bold py-2 px-4 rounded">
  Click me
</button>
```

- `bg-blue-500` → blue background
- `hover:bg-blue-700` → darker blue on mouse hover
- `text-white` → white text
- `font-bold` → bold text
- `py-2` → padding top and bottom (0.5rem)
- `px-4` → padding left and right (1rem)
- `rounded` → rounded corners
