

## Topic 2: Padding — The Spacing Foundation

### The Scale

Tailwind uses a **4px base scale** (0.25rem = 4px). Every number you see is multiplied by 4 to get pixels.

| Class | Value | Pixels |
|-------|-------|--------|
| `p-0` | 0 | 0px |
| `p-0.5` | 0.125rem | 2px |
| `p-1` | 0.25rem | 4px |
| `p-1.5` | 0.375rem | 6px |
| `p-2` | 0.5rem | 8px |
| `p-3` | 0.75rem | 12px |
| `p-4` | 1rem | 16px |
| `p-5` | 1.25rem | 20px |
| `p-6` | 1.5rem | 24px |
| `p-8` | 2rem | 32px |
| `p-10` | 2.5rem | 40px |
| `p-12` | 3rem | 48px |
| `p-16` | 4rem | 64px |
| `p-20` | 5rem | 80px |
| `p-24` | 6rem | 96px |

**The pattern:** `p-{number}` = padding on **all four sides**

---

### Directional Padding

Sometimes you don't want padding everywhere. You want it only on specific sides.

| Class | Meaning |
|-------|---------|
| `pt-{n}` | **p**adding **t**op only |
| `pr-{n}` | **p**adding **r**ight only |
| `pb-{n}` | **p**adding **b**ottom only |
| `pl-{n}` | **p**adding **l**eft only |

**Examples:**
- `pt-4` = padding-top: 16px
- `pl-2` = padding-left: 8px
- `pb-8` = padding-bottom: 32px

---

### Axis Padding (The Shortcuts)

| Class | Meaning |
|-------|---------|
| `px-{n}` | **p**adding on the **x**-axis (left + right) |
| `py-{n}` | **p**adding on the **y**-axis (top + bottom) |

**Examples:**
- `px-4` = padding-left: 16px AND padding-right: 16px
- `py-2` = padding-top: 8px AND padding-bottom: 8px

---

### Combining Them

You can mix and match. These are all valid together:

```jsx
// Heavy top/bottom, light left/right
<div className="px-4 py-8">Content</div>

// Only left padding, everything else tight
<div className="pl-6">Content</div>

// Equal all around
<div className="p-4">Content</div>
```

**Rule:** More specific classes override less specific ones if they target the same side. But usually you just pick the right combination from the start.

---

### When to Use What?

| Situation | Class Pattern |
|-----------|---------------|
| Button internal spacing | `px-4 py-2` |
| Card internal spacing | `p-6` |
| Section vertical breathing room | `py-16` |
| List item left indent | `pl-4` |
| Form input comfortable feel | `px-4 py-3` |
