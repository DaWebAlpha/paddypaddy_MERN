## Topic 3: Margin — Space *Outside* the Box

Padding pushes content *inward* from the border. Margin pushes the *entire box* outward from other elements.

**The mental picture:**

```
┌─────────────────────────────┐
│         MARGIN (outside)    │  ← pushes this box away from neighbors
│   ┌─────────────────────┐   │
│   │      BORDER         │   │
│   │   ┌─────────────┐   │   │
│   │   │   PADDING   │   │   │
│   │   │  ┌───────┐  │   │   │
│   │   │  │CONTENT│  │   │   │
│   │   │  └───────┘  │   │   │
│   │   └─────────────┘   │   │
│   └─────────────────────┘   │
└─────────────────────────────┘
```

---

### The Scale (Same as Padding)

| Class | Value | Pixels |
|-------|-------|--------|
| `m-0` | 0 | 0px |
| `m-1` | 0.25rem | 4px |
| `m-2` | 0.5rem | 8px |
| `m-4` | 1rem | 16px |
| `m-6` | 1.5rem | 24px |
| `m-8` | 2rem | 32px |

**Same ×4 rule.** `m-6` = 24px.

---

### Directional & Axis (Same Pattern as Padding)

| Class | Meaning |
|-------|---------|
| `mt-{n}` | **m**argin **t**op |
| `mr-{n}` | **m**argin **r**ight |
| `mb-{n}` | **m**argin **b**ottom |
| `ml-{n}` | **m**argin **l**eft |
| `mx-{n}` | **m**argin **x**-axis (left + right) |
| `my-{n}` | **m**argin **y**-axis (top + bottom) |

---

### The Critical Difference: Negative Margin

This is where margin gets interesting. Padding can never be negative. Margin can.

| Class | Meaning |
|-------|---------|
| `-mt-4` | Pulls element UP by 16px |
| `-ml-2` | Pulls element LEFT by 8px |
| `-mx-4` | Pulls both left and right by 16px |

**Use case:** Overlapping cards, pulling an icon closer to text, breaking out of containers.

```jsx
// Avatar overlapping a card header
<div className="-mt-8 mx-auto w-16 h-16 rounded-full bg-gray-300">
  {/* avatar image */}
</div>
```

---

### Auto Margin: The Layout Secret Weapon

| Class | Meaning |
|-------|---------|
| `mx-auto` | Centers horizontally (auto left + right margin) |
| `ml-auto` | Pushes element to the right |
| `mr-auto` | Pushes element to the left |
| `my-auto` | Centers vertically (in a flex container) |

**`mx-auto` is how you center a container:**

```jsx
<div className="max-w-md mx-auto">
  {/* This box is centered on the page */}
</div>
```

**`ml-auto` is how you push a nav link to the far right:**

```jsx
<nav className="flex">
  <a>Home</a>
  <a>About</a>
  <a className="ml-auto">Login</a>  {/* Pushed to the right */}
</nav>
```

---

### Margin Collapse (The Gotcha)

In normal document flow, vertical margins can **collapse**. If Box A has `mb-4` and Box B below it has `mt-4`, the gap between them is **16px**, not 32px. The larger margin wins, they don't add up.

This only happens with vertical margins in block layout. Not in flexbox or grid.
