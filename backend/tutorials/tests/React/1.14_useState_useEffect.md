# The 3 useEffect Cases You Must Master

These three patterns account for most React usage.

---

## Case 1: No Dependency Array

```jsx
useEffect(() => {
    console.log("Effect");
});
```

React thinks:

```text
After every render,
run this effect.
```

---

Example:

```jsx
const [count, setCount] = useState(0);
```

Click button 3 times:

```text
Render
Effect

Render
Effect

Render
Effect

Render
Effect
```

Runs every time.

---

## Case 2: Empty Dependency Array

```jsx
useEffect(() => {
    console.log("Mounted");
}, []);
```

React thinks:

```text
Run once after first render.
```

---

Sequence:

```text
Initial Render
↓
Mounted

Click Button
↓
Nothing

Click Again
↓
Nothing
```

Only once.

---

Common uses:

```text
Fetch API data
Initialize app
Setup listeners
```

---

## Case 3: Dependency Array With Values

```jsx
useEffect(() => {
    console.log("Count changed");
}, [count]);
```

React thinks:

```text
Watch count.
```

---

If count changes:

```text
Run effect.
```

If something else changes:

```text
Don't run effect.
```

---

# Visual Summary

### No Array

```jsx
useEffect(() => {
}, );
```

Meaning:

```text
EVERY RENDER
```

---

### Empty Array

```jsx
useEffect(() => {
}, []);
```

Meaning:

```text
FIRST RENDER ONLY
```

---

### Dependency Array

```jsx
useEffect(() => {
}, [count]);
```

Meaning:

```text
WHEN count CHANGES
```

# Practice Exercise

Create:

```jsx
const [name, setName] = useState("");
const [age, setAge] = useState(0);
```

Add:

```jsx
useEffect(() => {
    console.log("Name changed");
}, [name]);

useEffect(() => {
    console.log("Age changed");
}, [age]);

useEffect(() => {
    console.log("Mounted");
}, []);

useEffect(() => {
    console.log("Every render");
});
```

Then add two buttons:

```jsx
Increase Age
Change Name
```

Before clicking anything, predict the console.

Then click each button and predict again.

That exercise forces you to distinguish all three `useEffect` patterns, which is the key skill. Once you're comfortable with that, the next major topic is **controlled inputs (`value` + `onChange`)**, where React forms start making sense.
