### What you learned from this project

#### `useState`

```jsx
const [name, setName] = useState("");
const [age, setAge] = useState("");
const [language, setLanguage] = useState("");
```

Stores data that changes.

---

#### Controlled Inputs

```jsx
<input
    value={name}
    onChange={(e) => setName(e.target.value)}
/>
```

Flow:

```text
User types
↓
onChange fires
↓
setName(...)
↓
State updates
↓
Component re-renders
↓
Input receives new value
```

---

#### Derived UI

```jsx
{name}
```

is not stored separately.

React reads the current state and displays it.

---

#### Event Object

```jsx
(e) => setName(e.target.value)
```

`e` is the event.

```jsx
e.target
```

is the input element.

```jsx
e.target.value
```

is what the user typed.
