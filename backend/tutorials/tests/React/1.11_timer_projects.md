## Project 1: Digital Stopwatch

### What It Does
A simple stopwatch with Start, Stop, and Reset buttons. It counts seconds and displays minutes:seconds format (e.g., "01:45").

### Why This Project
It teaches:
- `useState` for multiple related values (running boolean, elapsed time)
- `useEffect` with `setInterval` and cleanup
- Derived state (formatting time from raw seconds)
- Event handlers that interact with state

---

### Requirements

1. **State variables** (all in one component):
   - `isRunning` (boolean, starts `false`)
   - `elapsedSeconds` (number, starts `0`)

2. **Display:**
   - Show time as `MM:SS` format (e.g., "00:05", "02:30")
   - Use a large `<p>` element

3. **Buttons:**
   - **Start:** Begins counting. Disabled when running.
   - **Stop:** Pauses counting. Disabled when not running.
   - **Reset:** Sets elapsed time back to 0. Also stops if running.

4. **Timer logic:**
   - When `isRunning` is `true`, increment `elapsedSeconds` by 1 every second
   - When `isRunning` is `false`, timer pauses
   - Use `useEffect` with `setInterval`
   - Include cleanup to clear interval

5. **Formatting logic:**
   - `minutes = Math.floor(elapsedSeconds / 60)`
   - `seconds = elapsedSeconds % 60`
   - Pad with zero: `"0${minutes}".slice(-2)` or similar

---

### Hints (Read Carefully)

**Hint 1: The interval setup**

```jsx
useEffect(() => {
  let interval;
  
  if (isRunning) {
    interval = setInterval(() => {
      setElapsedSeconds(prev => prev + 1);
    }, 1000);
  }
  
  return () => clearInterval(interval);
}, [isRunning]);
```

**Why this works:**
- When `isRunning` becomes `true`, effect runs, creates interval
- When `isRunning` becomes `false`, effect cleans up, clears interval
- When `isRunning` doesn't change, effect doesn't re-run
- `setElapsedSeconds(prev => prev + 1)` uses functional update so we don't need `elapsedSeconds` in dependency array

**Why not put `elapsedSeconds` in deps?**
If you do: `useEffect(..., [isRunning, elapsedSeconds])`, the effect re-runs every second because `elapsedSeconds` changes. The interval gets destroyed and recreated every second. It works but is inefficient. The pattern above is cleaner.

**Hint 2: Formatting time**

```jsx
const minutes = Math.floor(elapsedSeconds / 60);
const seconds = elapsedSeconds % 60;
const formatted = `${String(minutes).padStart(2, '0')}:${String(seconds).padStart(2, '0')}`;
```

`String(5).padStart(2, '0')` gives `"05"`. `String(45).padStart(2, '0')` gives `"45"`.

**Hint 3: Button disabled states**

```jsx
<button onClick={() => setIsRunning(true)} disabled={isRunning}>Start</button>
<button onClick={() => setIsRunning(false)} disabled={!isRunning}>Stop</button>
<button onClick={() => { setIsRunning(false); setElapsedSeconds(0); }}>Reset</button>
```

Reset sets both `isRunning` to `false` and `elapsedSeconds` to `0`. The order matters: setting `isRunning` to `false` triggers effect cleanup, which clears the interval. Then setting `elapsedSeconds` to `0` updates the display.

**Hint 4: Derived state vs. stored state**

You store `elapsedSeconds` (raw number). You derive `formatted` during render. You do NOT store `formatted` in state. Why? Because `formatted` is completely determined by `elapsedSeconds`. Storing it would be redundant and require keeping two values in sync.

function Button({ onClick, children, disabled }) {
    return (
        <button 
            
            className="rounded-md bg-blue-500 hover:bg-blue-600 cursor-pointer text-white font-bold py-2 px-4" 
            onClick={onClick} 
            disabled={disabled}
        >
            {children}
        </button>
    );
}

export default Button;


import { useState, useEffect } from "react";
import Button from "./components/Button";

function App() {
    const [isRunning, setIsRunning] = useState(false);
    const [elapsedTime, setElapsedTime] = useState(0); 

    useEffect(() => {
        let interval;
        
        // Only start the timer if isRunning is true
        if (isRunning) {
            interval = setInterval(() => {
                setElapsedTime(prev => prev + 1);
            }, 1000);
        }

        // Clean up the interval when isRunning changes or component unmounts
        return () => clearInterval(interval);
    }, [isRunning]);

    const minutes = Math.floor(elapsedTime / 60);
    const seconds = elapsedTime % 60;
    const formatted = `${String(minutes).padStart(2, '0')}:${String(seconds).padStart(2, '0')}`;

    return (
        <div className="p-6 text-center">
            <h1 className="text-2xl font-bold mb-2">Timer</h1>
            <p className="text-4xl font-mono mb-4">{formatted}</p>
            <div className="flex gap-2 justify-center">
                <Button onClick={() => setIsRunning(true)} disabled={isRunning}>Start</Button>
                <Button onClick={() => setIsRunning(false)} disabled={!isRunning}>Stop</Button>
                <Button onClick={() => { setIsRunning(false); setElapsedTime(0); }}>Reset</Button>
            </div>
        </div>
    );
}

export default App;
