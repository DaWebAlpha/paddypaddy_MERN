## What is Component Nesting?

**Nesting** means putting components inside other components. Just like HTML tags can sit inside other HTML tags, your custom React components can contain other custom components.

This is how you build real pages — a `Header` contains a `Logo` and `NavLinks`. A `Card` contains an `Image`, a `Title`, and a `Button`.

---

## Building a Nested Layout

Let's create a small page with three components working together. You already have `Title` and `Button`. Now let's make a `Card` that nests them both.

Create `src/components/Card.jsx`:

```jsx
import Title from './Title';
import Button from './Button';

function Card() {
  return (
    <div className="max-w-md p-8 bg-white rounded-2xl shadow-xl border border-gray-100">
      <Title />
      <p className="mt-4 text-gray-600 leading-relaxed">
        This is a description inside the card. Components can hold other components!
      </p>
      <div className="mt-6">
        <Button />
      </div>
    </div>
  );
}

export default Card;
```

| Word/Symbol | What It Means |
|-------------|---------------|
| `import Title from './Title'` | Brings in the `Title` component from the same folder. |
| `import Button from './Button'` | Brings in the `Button` component from the same folder. |
| `max-w-md` | Tailwind: maximum width medium (448px). The card won't grow wider than this. |
| `p-8` | Tailwind: padding on all sides (2rem / 32px). |
| `bg-white` | Tailwind: white background. |
| `rounded-2xl` | Tailwind: extra large rounded corners (16px radius). |
| `shadow-xl` | Tailwind: extra large shadow for a "floating" effect. |
| `border` | Tailwind: adds a 1px border. |
| `border-gray-100` | Tailwind: very light gray border. |
| `<Title />` | Our custom Title component, used inside the card. |
| `<p>` | A paragraph tag. |
| `mt-4` | Tailwind: margin-top (1rem / 16px). |
| `text-gray-600` | Tailwind: medium gray text. |
| `leading-relaxed` | Tailwind: increases line height for easier reading. |
| `<div className="mt-6">` | A wrapper div that adds top margin to push the button down. |
| `<Button />` | Our custom Button component, nested inside the card. |

**In plain English:** "Create a white card with a shadow and rounded corners. Inside it, put my Title, then some description text, then my Button — each spaced nicely apart."

---

## The Parent-Child Relationship

In this example:
- `Card` is the **parent** component.
- `Title`, `<p>`, `<div>`, and `Button` are **children** of `Card`.
- `Title` and `Button` are also **nested components** because they are custom components we built.

```
Card (parent)
├── Title (child component)
├── <p> (child HTML element)
└── <div> (child wrapper)
    └── Button (child component)
```

## Updating App.jsx

Now let's use `Card` in `App.jsx`:

```jsx
import Card from './components/Card';

function App() {
  return (
    <div className="min-h-screen flex items-center justify-center bg-gradient-to-br from-blue-50 to-indigo-100">
      <Card />
    </div>
  );
}

export default App;
```

| Word/Symbol | What It Means |
|-------------|---------------|
| `bg-gradient-to-br` | Tailwind: creates a background gradient. `to-br` means the gradient flows to the bottom-right corner. |
| `from-blue-50` | Tailwind: the gradient starts with a very light blue. |
| `to-indigo-100` | Tailwind: the gradient ends with a light indigo (purplish-blue). |

**In plain English:** "Center my Card on the screen with a soft blue-to-purple gradient background."

## Nesting Multiple Cards

You can reuse `Card` multiple times, and each one is independent:

```jsx
import Card from './components/Card';

function App() {
  return (
    <div className="min-h-screen flex flex-col items-center justify-center gap-8 p-8 bg-gradient-to-br from-blue-50 to-indigo-100">
      <Card />
      <Card />
      <Card />
    </div>
  );
}
```

| Word/Symbol | What It Means |
|-------------|---------------|
| `flex-col` | Tailwind: stack children vertically. |
| `gap-8` | Tailwind: 2rem of space between each card. |
| `p-8` | Tailwind: padding around the entire container so cards don't touch the screen edges. |

**In plain English:** "Stack three identical cards vertically with space between them, all centered on a gradient background."

Each `Card` has its own `Title`, text, and `Button`. They look the same but are completely separate.

## One More Example: A `Header` Component

Create `src/components/Header.jsx`:

```jsx
function Header() {
  return (
    <header className="w-full py-4 px-6 bg-white shadow-sm flex items-center justify-between">
      <span className="text-xl font-bold text-indigo-600">MyLogo</span>
      <nav className="flex gap-4">
        <a href="#" className="text-gray-600 hover:text-indigo-600">Home</a>
        <a href="#" className="text-gray-600 hover:text-indigo-600">About</a>
      </nav>
    </header>
  );
}

export default Header;
```

| Word/Symbol | What It Means |
|-------------|---------------|
| `<header>` | Semantic HTML tag for the top section of a page. |
| `w-full` | Tailwind: width 100% of the parent. |
| `py-4` | Tailwind: padding-top and padding-bottom (1rem). |
| `px-6` | Tailwind: padding-left and padding-right (1.5rem). |
| `shadow-sm` | Tailwind: small shadow for subtle depth. |
| `flex` | Tailwind: enables flexbox layout. |
| `items-center` | Tailwind: vertically centers items in the flex container. |
| `justify-between` | Tailwind: pushes items to opposite ends (logo left, nav right). |
| `<span>` | An inline text container. |
| `<nav>` | Semantic HTML tag for navigation links. |
| `<a href="#">` | A hyperlink. `#` means "no destination" (placeholder). |
| `hover:text-indigo-600` | Tailwind: changes text color on mouse hover. |

Now nest `Header` and `Card` together in `App.jsx`:

```jsx
import Header from './components/Header';
import Card from './components/Card';

function App() {
  return (
    <div className="min-h-screen bg-gray-50">
      <Header />
      <main className="flex items-center justify-center p-8">
        <Card />
      </main>
    </div>
  );
}

export default App;
```

| Word/Symbol | What It Means |
|-------------|---------------|
| `<main>` | Semantic HTML tag for the main content area of the page. |

**In plain English:** "Build a page with a Header at the top, and a Card centered in the main area below it."
