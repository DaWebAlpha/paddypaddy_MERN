## What is JSX?

JSX stands for **JavaScript XML**. It looks like HTML, but it's actually JavaScript. It allows you to write HTML-like code directly inside your JavaScript files.

Without JSX, you would have to write messy, hard-to-read code like this:

```javascript
React.createElement('h1', { className: 'text-2xl' }, 'Hello');
```

With JSX, you simply write:

```jsx
<h1 className="text-2xl">Hello</h1>
```

Much cleaner! Under the hood, a tool called **Babel** converts your JSX back into regular JavaScript before the browser sees it.

---

## The Rules of JSX

JSX has a few strict rules. Let's learn them one by one.

---

## Rule 1: JSX Must Return a Single Parent Element

You cannot return two sibling elements side-by-side. You must wrap them in one container.

```jsx
function Card() {
  return (
    <div className="p-4 bg-white rounded-lg shadow-md">
      <h2 className="text-xl font-bold text-gray-800">Title</h2>
      <p className="text-gray-600 mt-2">This is the description.</p>
    </div>
  );
}
```

| Word/Symbol | What It Means |
|-------------|---------------|
| `(` `)` | Parentheses around the return value. They let you write JSX across multiple lines without JavaScript getting confused. |
| `<div>` | A generic HTML container. It groups the `h2` and `p` together. |
| `className="p-4"` | Tailwind: adds padding on all sides (1rem / 16px). |
| `bg-white` | Tailwind: sets the background color to white. |
| `rounded-lg` | Tailwind: rounds the corners of the box (large radius). |
| `shadow-md` | Tailwind: adds a medium drop shadow. |
| `<h2>` | A sub-heading tag. |
| `text-xl` | Tailwind: makes the text extra large (20px). |
| `font-bold` | Tailwind: makes the text bold. |
| `text-gray-800` | Tailwind: dark gray text color. |
| `<p>` | A paragraph tag. |
| `text-gray-600` | Tailwind: medium gray text color. |
| `mt-2` | Tailwind: adds margin-top (0.5rem / 8px). |

**In plain English:** "Create a white card with rounded corners and a shadow. Inside it, put a bold dark title and a gray description below it."

**Why the wrapper?** React's `return` can only send back **one thing**. The `<div>` acts like a basket holding multiple items.

---

## Rule 2: Use `className`, Not `class`

In regular HTML, you write `class="..."`. In JSX, you **must** write `className="..."` because `class` is a reserved word in JavaScript (used for object-oriented programming).

```jsx
// ❌ Wrong in JSX
<div class="bg-blue-500">Hi</div>

// ✅ Correct in JSX
<div className="bg-blue-500">Hi</div>
```

---

## Rule 3: Close Every Tag

In HTML, some tags don't need closing (like `<img>` or `<br>`). In JSX, **every tag must close** — either with a closing tag or a self-closing slash.

```jsx
// ✅ Self-closing (good for tags with no children)
<img className="w-16 h-16 rounded-full" src="photo.jpg" alt="Me" />

// ✅ With closing tag (good for tags that wrap content)
<div className="p-2">Hello</div>
```

| Word/Symbol | What It Means |
|-------------|---------------|
| `<img` | The image tag. |
| `className="w-16 h-16 rounded-full"` | Tailwind: width 64px, height 64px, perfectly round (circle). |
| `src="photo.jpg"` | The source path to the image file. |
| `alt="Me"` | Alternative text for screen readers and if the image fails to load. |
| `/>` | The self-closing slash. It means "this tag ends here and has no children." |

---

## Rule 4: Use Curly Braces `{ }` for JavaScript Inside JSX

JSX is HTML-like, but it's still JavaScript. If you want to insert a dynamic value, expression, or variable, wrap it in curly braces.

```jsx
function Greeting() {
  const name = "Alice";
  const age = 25;

  return (
    <div className="p-6 bg-green-100 rounded-xl">
      <h1 className="text-2xl font-bold text-green-800">Hello, {name}!</h1>
      <p className="text-green-700 mt-2">You are {age + 5} years old in 5 years.</p>
    </div>
  );
}
```

| Word/Symbol | What It Means |
|-------------|---------------|
| `const` | Creates a constant variable (won't change). |
| `name` | A variable holding the string `"Alice"`. |
| `=` | Assigns the value on the right to the variable on the left. |
| `"Alice"` | A string (text) value. |
| `age` | A variable holding the number `25`. |
| `{name}` | Curly braces tell React: "This is JavaScript, not plain text. Insert the value of the `name` variable here." |
| `{age + 5}` | A JavaScript expression inside JSX. It calculates `25 + 5` and displays `30`. |

**In plain English:** "Store the name 'Alice' and age 25. Then draw a green box with a bold greeting that uses her name, and a sentence that calculates her age in 5 years."

---

## Rule 5: Comments Look Different

In JSX, you cannot use regular HTML comments (`<!-- -->`). You must use JavaScript-style comments inside curly braces.

```jsx
function Note() {
  return (
    <div className="p-4">
      {/* This is a comment inside JSX */}
      <p className="text-gray-500">Visible text</p>
    </div>
  );
}
```

| Word/Symbol | What It Means |
|-------------|---------------|
| `{` `}` | Curly braces switch back to JavaScript mode. |
| `/* */` | A JavaScript multi-line comment. |
| `{/* */}` | The full pattern for a JSX comment. |

## Full Example: Putting It All Together

```jsx
import React from 'react';
import ReactDOM from 'react-dom/client';

function ProfileCard() {
  const userName = "Sam";
  const isOnline = true;

  return (
    <div className="max-w-sm p-6 bg-white border border-gray-200 rounded-xl shadow-lg">
      <img 
        className="w-20 h-20 mx-auto rounded-full border-4 border-blue-400" 
        src="avatar.png" 
        alt="Profile" 
      />
      <h2 className="mt-4 text-center text-xl font-bold text-gray-900">{userName}</h2>
      <p className="text-center text-sm text-green-600 font-medium">
        {isOnline ? "Online" : "Offline"}
      </p>
    </div>
  );
}

const root = ReactDOM.createRoot(document.getElementById('root'));
root.render(<ProfileCard />);
```

| Word/Symbol | What It Means |
|-------------|---------------|
| `max-w-sm` | Tailwind: maximum width small (384px). Prevents the card from stretching too wide. |
| `border` | Tailwind: adds a default light gray border. |
| `border-gray-200` | Tailwind: sets the border color to very light gray. |
| `shadow-lg` | Tailwind: adds a large, soft drop shadow. |
| `w-20` | Tailwind: width 80px. |
| `h-20` | Tailwind: height 80px. |
| `mx-auto` | Tailwind: margin-left and margin-right auto. Centers the image horizontally. |
| `border-4` | Tailwind: border thickness 4px. |
| `border-blue-400` | Tailwind: medium-light blue border. |
| `mt-4` | Tailwind: margin-top 1rem (16px). |
| `text-center` | Tailwind: centers text horizontally. |
| `text-gray-900` | Tailwind: very dark gray (almost black). |
| `text-sm` | Tailwind: small text size (14px). |
| `text-green-600` | Tailwind: medium green. |
| `font-medium` | Tailwind: medium font weight (not bold, not thin). |
| `{isOnline ? "Online" : "Offline"}` | A **ternary operator**. It checks: is `isOnline` true? If yes, show "Online". If no, show "Offline". |

**In plain English:** "Create a profile card with a centered circular avatar, the user's name, and a green 'Online' status. The card has a white background, rounded corners, a light border, and a soft shadow."
