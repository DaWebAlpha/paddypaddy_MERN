## 🛠️ Step 1: Create Your Project

Open your terminal and run:

```bash
npm create vite@latest myapp -- --template react
cd myapp
npm install
npm install tailwindcss @tailwindcss/vite
```

| Command | What It Does |
|---------|--------------|
| `npm create vite@latest` | Uses the Vite tool to scaffold a new project. |
| `myapp` | The name of your project folder. |
| `-- --template react` | Tells Vite to use the React template. |
| `cd myapp` | Moves into the project folder. |
| `npm install` | Downloads all the default React dependencies. |
| `npm install tailwindcss @tailwindcss/vite` | Installs Tailwind CSS and its official Vite plugin.  |

---

## ⚙️ Step 2: Configure Vite

Open `vite.config.js` and update it to this:

```js
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';
import tailwindcss from '@tailwindcss/vite';

export default defineConfig({
  plugins: [
    react(),
    tailwindcss(),
  ],
});
```

| Word/Symbol | What It Means |
|-------------|---------------|
| `import` | Brings in code from other files/packages. |
| `defineConfig` | A Vite helper that gives you autocomplete when editing config. |
| `react()` | The React plugin for Vite (handles JSX, Fast Refresh, etc.). |
| `tailwindcss()` | The Tailwind plugin that processes your utility classes. |
| `plugins: [...]` | An array. Vite runs each plugin in order when building your app. |

**In plain English:** "Vite, when you start my app, first use the React plugin, then use the Tailwind plugin so my classes actually work."

---

## 🎨 Step 3: Import Tailwind in Your CSS

Open `src/index.css` and replace everything with just this one line:

```css
@import "tailwindcss";
```

That's it! Tailwind v4 uses this single import to load everything — no more `@tailwind base; @tailwind components; @tailwind utilities;`. 

---

## 🚀 Step 4: Start Your Dev Server

```bash
npm run dev
```

Your app will open at `http://localhost:5173/`.

---

## ✅ Step 5: Test That Tailwind Works

Open `src/App.jsx` and replace everything with:

```jsx
function App() {
  return (
    <h1 className="text-3xl font-bold text-blue-600 underline">
      Tailwind is Working! 🎉
    </h1>
  );
}

export default App;
```

If you see a large, bold, blue, underlined heading — you're all set! 🎉
