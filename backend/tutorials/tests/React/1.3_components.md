## What is a Component?

A **component** is a reusable piece of your user interface. Think of it like a custom HTML tag that you invent and define yourself.

Every component in React is just a **JavaScript function** that returns JSX. The function name **must start with a capital letter** — this is how React tells the difference between a regular HTML tag (`<div>`) and your custom component (`<Header>`).

---

## Building Your First Component

Let's create a simple `Button` component. Create a new file at `src/components/Button.jsx`.

```jsx
function Button() {
  return (
    <button className="px-4 py-2 bg-blue-500 text-white rounded-lg hover:bg-blue-600">
      Click Me
    </button>
  );
}

export default Button;
```

| Word/Symbol | What It Means |
|-------------|---------------|
| `function` | Creates a reusable block of code. |
| `Button` | The name of our component. **Capital B** — this is required! |
| `()` | No inputs yet (we'll add props later). |
| `{` `}` | Wraps everything the function does. |
| `return` | Sends back the JSX to be drawn on screen. |
| `<button>` | A regular HTML button tag. |
| `className="..."` | Tailwind utility classes. |
| `px-4` | Tailwind: padding-left and padding-right of 1rem (16px). |
| `py-2` | Tailwind: padding-top and padding-bottom of 0.5rem (8px). |
| `bg-blue-500` | Tailwind: medium blue background. |
| `text-white` | Tailwind: white text color. |
| `rounded-lg` | Tailwind: large rounded corners. |
| `hover:bg-blue-600` | Tailwind: when the mouse hovers over the button, change the background to a darker blue. |
| `Click Me` | The text label inside the button. |
| `</button>` | Closes the button tag. |
| `export default Button;` | Makes this component available for other files to import. `export` means "share this," `default` means "this is the main thing this file exports." |

**In plain English:** "I invented a new tag called `<Button>`. When used, it draws a blue clickable button with white text, rounded corners, and a hover effect."

## Using Your Component

Now open `src/App.jsx` and use your new component:

```jsx
import Button from './components/Button';

function App() {
  return (
    <div className="min-h-screen flex items-center justify-center bg-gray-100">
      <Button />
    </div>
  );
}

export default App;
```

| Word/Symbol | What It Means |
|-------------|---------------|
| `import` | Brings in code from another file. |
| `Button` | The name of the component we're importing. |
| `from` | Part of the import statement. |
| `'./components/Button'` | The file path. `./` means "start in this folder," then go into `components/`, then `Button.jsx`. You can leave off `.jsx` — React knows. |
| `<Button />` | Using our custom component! It looks like an HTML tag, but it's the function we just wrote. The `/` means it has no children and closes itself. |

**In plain English:** "Go get my Button component from the components folder, then draw it in the center of a light gray screen."

---

## Why Components Are Powerful

You can use `<Button />` as many times as you want:

```jsx
import Button from './components/Button';

function App() {
  return (
    <div className="min-h-screen flex flex-col items-center justify-center gap-4 bg-gray-100">
      <Button />
      <Button />
      <Button />
    </div>
  );
}
```

| Word/Symbol | What It Means |
|-------------|---------------|
| `flex-col` | Tailwind: stack children vertically (column) instead of side-by-side (row). |
| `gap-4` | Tailwind: adds space (1rem / 16px) between each child element. |

**In plain English:** "Stack three buttons vertically in the center of the screen with space between them."

Each `<Button />` is an **independent copy**. They look the same, but they are separate instances.

## Another Example: A `Title` Component

Create `src/components/Title.jsx`:

```jsx
function Title() {
  return (
    <h1 className="text-4xl font-extrabold text-gray-900 tracking-tight">
      Welcome to React
    </h1>
  );
}

export default Title;
```

| Word/Symbol | What It Means |
|-------------|---------------|
| `text-4xl` | Tailwind: very large text (36px). |
| `font-extrabold` | Tailwind: extra thick text weight. |
| `tracking-tight` | Tailwind: slightly reduces space between letters for a sleek look. |

Now use it in `App.jsx`:

```jsx
import Title from './components/Title';
import Button from './components/Button';

function App() {
  return (
    <div className="min-h-screen flex flex-col items-center justify-center gap-6 bg-gray-50">
      <Title />
      <Button />
    </div>
  );
}

export default App;
```

**In plain English:** "Draw my custom Title, then draw my custom Button, stacked vertically with space between them, centered on the screen."
